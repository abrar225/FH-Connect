# FH-Connect: Deployment Guide 🚀

This guide outlines the steps to take **FH-Connect** from a local development environment to a production server.

---

## 🔐 1. Environment Variables Check

Before deploying, ensure you have the following secrets configured in your production environment (e.g., Vercel, Railway, Docker).

### Backend (`.env`)
| Variable | Description | Source |
| :--- | :--- | :--- |
| `GROQ_API_KEY` | LLM Key for Llama models | [Groq Cloud](https://console.groq.com/) |
| `GEMINI_API_KEY` | LLM Key for Gemini models | [Google AI Studio](https://aistudio.google.com/) |
| `DEEPGRAM_API_KEY` | Transcription Key | [Deepgram](https://console.deepgram.com/) |
| `SUPABASE_URL` | Your Project URL | [Supabase](https://supabase.com/) |
| `SUPABASE_SERVICE_ROLE_KEY` | Admin key for DB access | Supabase Dashboard |
| `DATABASE_URL` | Postgres Connection String | Supabase/Postgres |
| `LIVEKIT_URL` | WebSocket URL for media | [LiveKit Cloud](https://cloud.livekit.io/) |
| `LIVEKIT_API_KEY` | LiveKit Credentials | LiveKit Dashboard |
| `LIVEKIT_API_SECRET` | LiveKit Credentials | LiveKit Dashboard |

### Frontend (`.env.local`)
| Variable | Description |
| :--- | :--- |
| `NEXT_PUBLIC_SUPABASE_URL` | Public Supabase URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Public Anon Key |
| `NEXT_PUBLIC_LIVEKIT_URL` | Public LiveKit WSS URL |
| `NEXT_PUBLIC_API_BASE` | URL of your deployed Backend |

## 📦 2. Backend Deployment (FastAPI)

1.  **Clone & Install**:
    ```bash
    cd backend
    python -m venv venv
    source venv/bin/activate  # or venv\Scripts\activate on Windows
    pip install -r requirements.txt
    ```
2.  **Run with Production Server**:
    Use `uvicorn` with multiple workers if needed:
    ```bash
    uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
    ```
3.  **Docker (Recommended)**:
    Create a `Dockerfile` in the `backend` directory:
    ```dockerfile
    FROM python:3.11-slim
    WORKDIR /app
    COPY . .
    RUN pip install --no-cache-dir -r requirements.txt
    CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
    ```

## 🌐 3. Frontend Deployment (Next.js)

The easiest way to deploy the frontend is via **Vercel**.

1.  **Connect Repo**: Link your GitHub repository to Vercel.
2.  **Environment Variables**: Add all `NEXT_PUBLIC_` variables in the Vercel Dashboard.
3.  **Build Command**: `npm run build`
4.  **Install Command**: `npm install`

---

## 🏗️ 4. Infrastructure Setup

### Supabase
- Ensure your `meetings` and `tasks` tables are created.
- (Optional) Enable Row Level Security (RLS) for production.

### LiveKit
- Use **LiveKit Cloud** for minimal devops, or self-host using their [deployment guide](https://docs.livekit.io/realtime/self-hosting/deployment/).

### CORS Configuration
> [!IMPORTANT]
> Update `backend/app/main.py` to replace `allow_origins=["*"]` with your actual frontend URL (e.g., `https://fh-connect.vercel.app`) before going live.
