## graphify

This project has a graphify knowledge graph at graphify-out/.

- 🚨 **MANDATORY**: After modifying any code or files in this project, you MUST run `backend/.venv/bin/graphify update .` to keep the knowledge graph current.
- Before answering architecture or codebase questions, read `graphify-out/GRAPH_REPORT.md` for god nodes and community structure.
- Use `graphify query "<question>"` or `graphify explain "<concept>"` for cross-module navigation instead of raw file scanning.
